THE LAST PALADIN

Hello this is a project ive been working on for 1.5 years. I just finished my c++ sfml game and its published on itch.io! This game is a in a 2D side scroller made enitrely from SFML 3.0 in visual Studio C++.

SEPTEMBER 2026 UPDATE:
---------------------------------------------------------------------
I recently decided to update my game substantially by adding an online multiplayer battle mode. This was in the works since March 2026, and I'm very happy to say I've deployed it to Azure and anyone can play over the internet! I learned so much about not only how multiplayer games work, but how computers across the world talk to each other over the internet. I used Docker and Azure as my tools to deploy mu game and lobby servers, and I learned a lot about these two tools. Right now the game is still in beta, theres some known bugs with the game containers, but I wanted to provide an update on my game that I've been working on.
